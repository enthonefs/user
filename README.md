# Aplicação de Cadastro de Usuários  

Este é um sistema básico desenvolvido em **Java** utilizando o **Spring Boot**, que permite realizar operações de cadastro, listagem, edição e exclusão de dados de usuários.  

O objetivo do projeto é demonstrar de forma simples como estruturar uma aplicação back-end com as funcionalidades essenciais de manipulação de informações.  

## Tecnologias utilizadas  
- **Java**  
- **Spring Boot**
- **JWT**  
- **Spring Security**  

## Funcionalidades  
- Cadastrar novos registros  
- Listar registros existentes  
- Atualizar informações  
- Excluir registros
